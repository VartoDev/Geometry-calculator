# Geometry Calc

My first Python project created by me! 🎉

Geometry Calc is a simple chatbot-based calculator that can calculate the **surface area** and **volume** of different 3D shapes. Instead of clicking through menus, you simply talk to the bot and enter the required values.

This project helped me learn the very basics of python.
## Features

- Calculate volumes of different geometric shapes
- Calculate surface areas
- Simple chatbot-style interaction
- Beginner-friendly Python project
- Fast and easy to use

## Supported Shapes

-Cylinder 
-Cone 
-Pyramid
